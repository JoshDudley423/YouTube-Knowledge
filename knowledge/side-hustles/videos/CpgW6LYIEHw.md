# The Most Useful AI Tool You've Never Heard Of
Channel: The Koerner Office | https://www.youtube.com/watch?v=CpgW6LYIEHw | Published: 2026-09-15

Sponsored interview with Jaylen (Violoop), maker of a hardware AI device that watches a user's screen continuously to act as a proactive AI "coworker/intern." More about the product/technology than a specific business model, but includes concrete money-making applications the founder describes.

## What Violoop is (product overview)
- A hardware device (connects to a computer via a single USB-C cable) that continuously watches everything on the user's screen (described as "YouTube live" access vs. prior AI's static screenshot/text access) and acts proactively, not just reactively.
- Framed as a live, embedded coworker/intern rather than a chat tool you have to prompt — it can draft replies, take actions, and surface suggestions based on what it observes without being asked.
- Privacy/architecture: video/screen data is processed entirely on-device (never sent to the cloud/any AI lab or AWS); runs its own local/on-device "agentic model," builds a persistent local memory graph unique to the user, and includes a dedicated security chip that (a) enforces yes/no permission gating on irreversible actions (deleting files, sending messages) and (b) stores credentials/passwords/API keys in a vault that even a physically broken device can't have extracted.
- Reported average time savings from early users: ~2 hours/day (roughly one extra working day per week), used both for tasks that run automatically before the user starts work and for tasks that continue after they log off.

## Demonstrated capabilities relevant to running a business
- **Live document/context assistance**: watching a resume in a Word doc, it proactively offers to generate a candidate scorecard, interview questions, or a fit analysis; watching a partnership/legal agreement, it offers a risk summary, key terms extraction, or negotiation prep — all without the user typing a prompt, just confirming a suggested action.
- **Live messaging assistance**: sees an incoming message asking for your office address or a meeting time and pre-drafts the reply for one-tap confirmation.
- **Invoice/expense tracking (cited as the most common request)**: connected to Gmail, it detects incoming invoices, scans them, and logs them (amount, date, attachment) into a personal Google Sheet automatically — described as leaving the user "tax season ready" with minimal manual work. Applies to both business owners and regular employees tracking personal spend.
- **Content research for non-business users**: can browse a dozen+ sites (including ones normally hard for AI crawlers to access, e.g. LinkedIn) and return a consolidated summary on a research topic.
- **"Away mode"**: lets the device keep working on long-running tasks (video exports, 3D renders, monitoring a YouTube upload's completion status) while the user is away from the computer, then hand off/notify when a task finishes so the user can review/approve before publishing.
- **End-to-end business workflow automation example**: detected an incoming email requesting a quote for 100 units from a reseller, asked permission to build a quotation, pulled current pricing/discount tiers from a Google Sheet, generated a formal PDF quote via QuickBooks, attached it to a draft reply — leaving only a final "send" click for the user. Demonstrates chaining across email → spreadsheet → accounting software → email.
- **Marketing/ad analytics use case**: helped build a unified tracking dashboard across ~200-300 simultaneous Meta ad campaigns (views, CPA, CTR per ad) that would otherwise be unmanageable to track manually, and can generate new ad creative/images to swap out underperforming assets.
- **Idea-surfacing / accountability use case**: because it observes daily activity/browsing, it can identify a user's genuine interests (as a starting point for what business to build) and flag their own "blind spots" — e.g., proactively noting "you haven't mentioned launching your D2C site in 3 days, is that still on your roadmap?" — used by the founder himself roughly weekly to check his own follow-through.
- **Idea-generation angle specifically for beginners**: because it observes what someone spends time on (e.g., watching fishing videos daily), it can surface an otherwise-unacknowledged interest as a possible business direction, and can mine the comment sections of frequently-watched content for unaddressed pain points/business opportunities.

## Concrete low-cost ways to start a business using this kind of AI tool (framework given by the guest)
- Cost of building a simple storefront/landing page has dropped to near zero — build several small test websites cheaply (e.g., a personal branding site for artists, a secondhand goods site sourced from Facebook Marketplace) and see which one gets traction with friends/family/social media before committing further.
- Pattern observed among engineers: find a useful open-source GitHub project, build a nicer front-end for it, localize it into other languages, and sell subscription access (e.g., $10-20/month) into markets less exposed to a given technology (examples given: Japan, Korea, Vietnam) — some people running this from anywhere (cited "digital nomads in Bali").
- General advice for someone starting from zero: run several small, low-cost experiments simultaneously rather than committing to one idea; use whichever gets positive traction as the foundation to build further.

## Roadmap / current limitations disclosed
- On-device agentic model can currently reliably execute agentic tasks of about 5-8 sequential steps (e.g., find file → extract data → rename → send); the company's stated goal is pushing on-device models to 20-30-step workflows.
- On-device model capability is currently comparable to roughly GPT-3.5/GPT-4 era benchmarks, expected to improve quickly via over-the-air model updates without users losing their accumulated memory/context.
- Context/memory buildup time: if a user proactively connects third-party tools (Notion, Obsidian, Salesforce, Monday, Linear, etc.), the device can become useful within hours; without active setup, expect roughly 3 days to a week of passive observation before it has enough context to be helpful.
- Team/multi-user accounts not addressed in this episode (personal/individual device use case only).
