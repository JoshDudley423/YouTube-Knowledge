# AI Agents Are Finally Easy to Set Up
Channel: The Koerner Office | https://www.youtube.com/watch?v=XQJWYvbAaOg | Published: 2026-05-28

This is a tool-building tutorial video, not a specific business-idea pitch — the core "side hustle" angle is using AI agents for first-mover advantage (finding trending topics/business ideas before competitors) and a tangential idea for an AI-implementation agency.

- Core concept: first-mover advantage in content/business — being first to cover a trending topic or launch in a new niche captures a disproportionate share of attention. Illustrative example given (not sourced data, just an analogy): if a new study drops and one creator is first to cover it, they might get 10M views; the second creator covering the same topic might get ~2M views; the third only ~200,000 — an 80/20-style dropoff for being first vs. late.
- Proposed use of AI to capture that first-mover edge: build a personal AI agent that continuously scans the internet for trending topics/novel business ideas in a chosen niche, so you can be first to write/post/build about them.
- Tools demonstrated:
  - **OpenClaw** (referred to as "Open Claw" in the transcript) — a personal AI agent/assistant framework that runs on a server and can be controlled via Telegram, Slack, or WhatsApp, with a library of ~52 pre-built "skills" (e.g., sending iMessages, adding to Apple Notes, accessing 1Password, GitHub, web browsing/search).
  - **Hostinger** (sponsor) — used to host the OpenClaw agent on a managed server so it runs 24/7 without needing your own computer left on. Framed as cheaper and easier than buying a dedicated Mac mini (~$700) plus peripherals to self-host.
- Step-by-step setup shown:
  1. Sign up at hostinger.com (with a "kerneropenclaw" affiliate link), choose "Managed OpenClaw" — no setup fee, no per-agent fee, no coding required, unlimited bots/automations. Promo code "kerneroffice" for 10% off.
  2. Enable "instant web search" (free) so the agent can browse the internet.
  3. Connect an AI model via API key — presenter used his own Anthropic (Claude) API key (obtained by logging into the Anthropic console) rather than paying an extra ~$6 for Hostinger to provision one; recommends non-technical users who don't already have an API key just pay for Hostinger's provisioned key instead.
  4. Set up messaging via Telegram (connect through @BotFather in Telegram, name your bot, generate a token, paste it into Hostinger, approve the pairing code) — took about 7 minutes total for the whole setup in the demo.
  5. Default model was Claude Haiku (cheaper/older); presenter recommends upgrading to a stronger model (referenced as "Opus 4.7" in the video, likely meaning the newest available Opus model at time of filming) for better output quality.
  6. If web search misbehaves, install the "web_search" and "web_fetch" skills from ClawHub (a skills marketplace within OpenClaw) rather than relying on generic "browser automation."
- Example prompt used to configure the agent as a trend-research assistant: "You are a trend research assistant for novel small business ideas that are approachable. When I ask for ideas, search the web for the top three trending novel and approachable business ideas and stories of people building cool products or services. For each topic, write a one-sentence summary and suggest one content angle I can post about today. Send it as a clean numbered list."
- Demonstrated the agent successfully returning trending business ideas both generically and refined to a specific niche (e.g., "find three trending biz ideas from the last month or two in the home service niche with specific stories attached") — took roughly 15 seconds to a minute per query once configured correctly, and worked identically from both Telegram (mobile) and the Hostinger web console.
- Suggested further upgrades (not built in the video, just proposed): train/fine-tune the agent on your own past content/writing voice (e.g., upload prior transcripts) so its output matches your style; integrate with Zapier, Gmail, or Twilio so the agent can proactively text/call/email you when it finds something relevant, instead of requiring you to manually query it.
- Explicitly flagged limitation: as configured in the demo, the agent is "not much better than a Google search or Reddit search" — the real value only comes from these further integrations/customizations layered on top.
- Tangential business idea mentioned in closing: an AI-implementation agency helping small business owners set up AI agents (like OpenClaw) for their own customer service — noted that the same Hostinger/OpenClaw setup used in this tutorial could be resold/reused for that purpose at no extra infrastructure cost, but this is only briefly mentioned, not elaborated with pricing or a concrete plan.
- Caveats: this video is Hostinger-sponsored content (disclosed) with an affiliate/promo code; no revenue, cost, or client numbers are given for either the trend-agent workflow or the AI-implementation-agency idea — it's a tools/how-to demo, not a validated business case study.
