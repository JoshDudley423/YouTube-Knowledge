# MIND. BLOWN! I Just Paid ChatGPT Operator $200 to Build a Business
Channel: The Koerner Office | https://www.youtube.com/watch?v=QfWVeXHM7YI | Published: 2025-01-28

Screen-recorded demo of Chris Koerner using OpenAI's "Operator" agent (part of the $200/month ChatGPT Pro plan) to automate outreach for a free-piano-hauling side hustle on Facebook Marketplace.

## The idea
- "Piano flipping/hauling" business model: every day in a given metro, 40-60 people list pianos as FREE on Facebook Marketplace because they're heavy (~600 lb), hard to move, and unwanted liabilities. An operator lines up multiple free-piano pickups in one area/day, rents a U-Haul, collects a fee from each seller to haul the piano away, then disposes of it (dump) or ideally donates it.
- New twist demonstrated here: use an AI agent (ChatGPT's "Operator") to autonomously search Marketplace, message every free-piano lister with a pickup offer, log responses in a spreadsheet, and monitor for replies — largely removing the need for a human (or a cheap virtual assistant) to do this outreach manually.

## Numbers
- Charge per piano pickup: $200/pickup (per seller who agrees).
- U-Haul rental cost: ~$50 base + $0.75/mile.
- Estimated volume: ~40-60 pianos listed free per day in DFW metro; model assumed 40/day, ~280/week.
- Assumed conversion: ~10% of sellers agree to pay $200 for pickup → ~28 people/week × $200 = $5,600/week gross.
- Koerner's projection: at that volume/pricing, "could be a six-figure business," with AI handling outreach/logging (low-level work) and a human/crew handling the physical hauling (gas + labor costs not itemized beyond the U-Haul rate).
- ChatGPT Operator (Pro plan) cost: $200/month.
- Cost comparison offered: if launching without the AI, Koerner says he'd hire a virtual assistant to do the same outreach/logging work for $4-8/hour.
- Live demo result in ~15 minutes of recording: AI messaged 3 sellers, got 1 response (a decline — "we are giving things away, I don't want to pay to haul them off").

## Process / how to do it
1. In ChatGPT Operator (already logged into the user's personal Facebook account), prompt it to: open Facebook Marketplace, search a target metro area for "piano" listings with a max price of $0 (to surface only free listings).
2. Instruct it to message each seller offering to pick up the piano for a $200 fee, using a standardized outreach message (a "pickup only, you will need a truck" style note was auto-suggested).
3. Confirm/approve the agent's actions live at first (it asks permission before sending), but the agent also proceeded to send further messages on its own without additional prompting once given the task.
4. Direct the agent to log every contacted listing into a blank Google Sheet, auto-creating appropriate columns, including a link back to each Marketplace listing.
5. Have the agent add a checkbox column and monitor Marketplace messages, checking the box when a seller responds (agent handled this with some visible confusion/imprecision — see caveats).
6. Idea floated (not executed in the video): scale by having AI run this searching/messaging/logging loop continuously ("it could do this all night") across a wider search radius, while a human/crew executes the actual pickups.
7. Koerner mentions he already purchased the domain "pianomovers.com," suggesting an intent to formalize this as a standalone branded business.

## Tools/platforms/resources named
- ChatGPT Operator (OpenAI's $200/month Pro-tier agentic browsing tool) — drives Facebook Marketplace search, messaging, and Google Sheets logging autonomously from natural-language prompts.
- Facebook Marketplace — sourcing free piano listings and sending buyer/seller messages.
- Google Sheets — used as the auto-generated CRM/log of contacted listings, links, and response status.
- U-Haul — named as the truck rental used for actual physical pickups (~$50 + $0.75/mile).

## Caveats / risks
- This is an early/rough demo, not a proven, scaled operation — only 3 messages were sent and 1 response (a decline) was received on camera; no completed paid pickup shown.
- The agent made mistakes during the live run: it searched "pianos" (plural) instead of "piano" (potentially missing/adding irrelevant listings), left some spreadsheet cells blank unexpectedly, and appeared to "click on the wrong thing" / behave erratically ("like it has ADHD") while checking response checkboxes — reliability is clearly imperfect and needs human supervision.
- Operator pauses automatically after the user navigates away from its tab for ~30 seconds to a minute, limiting true "set and forget" automation — requires keeping the tab open/visible (e.g., on a second monitor).
- Ethical/reputational tension acknowledged explicitly: charging to hypothetically then dump "beautiful musical instruments" rather than donate them; Koerner notes donation would be the ideal outcome but "nobody wants them" in practice.
- Uses the operator's real, personal Facebook account to message strangers autonomously — raises platform ToS/account-risk questions not addressed in the video (e.g., risk of the account being flagged for automated/bot-like messaging behavior).
- Economics presented ($5,600/week) are a back-of-envelope projection based on an assumed 10% response/conversion rate, not validated data from an actual running operation.
