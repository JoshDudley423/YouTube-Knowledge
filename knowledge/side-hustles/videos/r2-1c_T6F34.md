# How to Build & Sell Micro Apps in 2026 (Using Only AI)
Channel: The Koerner Office | https://www.youtube.com/watch?v=r2-1c_T6F34 | Published: 2026-01-04

- Idea: build niche vertical SaaS (micro CRM) for a specific local/home-service industry using AI coding tools, no coding skill required, then sell as a monthly subscription.
- Niche selection method: ask an AI (Claude) "what are 10 niches in [category] growing like crazy backed by hard data" to find a fast-growing, highly fragmented market with many solo operators (avoids concentrated markets like EV charger installation where a few big players dominate). Candidates surfaced: EV charger installation, pool service/maintenance (growing 12%/yr), solar panel cleaning, water damage restoration. He picked pool service.
- Market sizing example: ~79,000 pool service businesses in the US. At $20/month and 1,000 customers (1.5% of market) = $20,000/month. At $100/month, 1,000 customers = $100,000/month (lower conversion but higher profit).
- Process demonstrated:
  1. Prompt AI for niche selection (per above).
  2. Prompt the coding AI with a specific, narrow spec: "dead simple but super niche CRM for [operator type], don't overload with fields, make clear it's built for this industry (not generic like HubSpot), no coding experience, build the web app and show me the UI ASAP."
  3. Run the same prompt across multiple AI tools simultaneously and compare speed/quality/UI (he tested Claude Code, Replit, ChatGPT).
  4. Iterate with follow-up prompts for missing features (e.g., "make these records editable").
  5. Add payment: Stripe integration (Claude Code can build this).
  6. Find first customers via niche communities, get free users for feedback/reviews/referrals, then convert to paid.
- Tool comparison (build test for the same CRM spec):
  - Claude Code: ~117 seconds, best UI, auto-inferred appropriate fields (pool type: gunite/fiberglass/vinyl/above-ground/commercial/spa; pool size, service day, frequency, gate code, rate per visit) without being told to. One follow-up prompt needed to make records editable. Ranked #1.
  - ChatGPT: ~4 minutes total; gave raw code with no default preview (had to explicitly ask to see it); UI described as dated/ugly. Ranked #3 (last) — framed as a consumer thought-partner tool, not suited for non-technical builders.
  - Replit: took ~16 minutes (quoted 20 originally) — 8x longer than Claude Code; UI similar to Claude's build but more dated-looking (black/white sidebar), weaker tagging. Ranked #2 because it did eventually produce a working product.
- Customer acquisition tactics named:
  - Facebook Groups: search the niche term, filter to local groups, prefer private/moderated groups with recent active posts over big/spammy public groups (a large member count with low engagement is a red flag). Join, ask what features an ideal CRM would have, implement feedback, then circle back to commenters offering free access in exchange for reviews/referrals/case studies.
  - Gummy Search: AI tool that mines Reddit for pain points/feature requests within an industry.
  - Claude's "deep research" mode: prompt it to research what pain points/likes/dislikes an industry has with existing software and who the big competitors are; use this both to build a better product and to write more effective ad copy (lowers customer acquisition cost).
  - Google Trends: check search interest for "[industry] software" to confirm the category is growing (pool service software trend was spiking through 2025 in this example).
  - Cold outreach/cold email: use a scraping tool like Outscraper to scrape all businesses in the target industry/area (no coding needed), then text/call/email offering free trial (90 days or fully free until they hit their first 5 customers, then convert to paid).
  - Facebook custom audiences: upload the full scraped list of businesses (e.g., all 79,000 pool service businesses) as a custom audience so Facebook only serves ads to that specific niche.

Caveats/risks:
- Picking a shrinking/niche-within-niche category (example given: epoxy flooring) makes the same play "harder" — success is still possible but you're fighting the market instead of riding growth.
- Not knowing the target industry well enough to know what features actually matter is a real gap — mitigated by gathering direct operator feedback rather than guessing.
