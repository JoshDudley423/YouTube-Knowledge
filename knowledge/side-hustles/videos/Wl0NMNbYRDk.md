# The Most Passive Online Side Hustle I've Ever Seen
Channel: The Koerner Office | https://www.youtube.com/watch?v=Wl0NMNbYRDk | Published: 2026-04-10

- Idea: build single-purpose "tool sites" (calculators, quizzes, generators) using AI/vibe-coding, monetize with display ads + email capture. Pitched as near-passive once built (claims ~1 hour/week upkeep, no employees needed).
- Proof points / benchmarks cited:
  - A simple paycheck calculator site gets 700,000+ unique visitors/month; valued at ~$1.1M based on ad revenue alone.
  - A calorie calculator gets 456,000 organic visitors/month; ad-revenue valuation in the six figures.
  - Omni Calculator (Poland-based, started by one person learning to code) grew to 3,700+ calculators, 17M visitors/month, 70 employees, $500K+/month revenue (mostly profit). Framed as inspirational outlier, not a realistic target.
  - Per Ahrefs, ~36,000 distinct keyword clusters contain the word "calculator" (e.g., "mortgage calculator," "15-year mortgage calculator," "VA loan mortgage calculator") — described as not winner-take-all; many niche calculator sites each pull meaningful traffic.
- How to pick a niche/tool:
  - Look for high or growing search volume + a specific, narrow problem to solve (a "supply/demand imbalance": more search volume than competing sites).
  - Use Ahrefs/SEMrush/ChatGPT/Claude to find core keywords and long-tail variants (long-tail = lower volume but less competition).
  - Cross-check candidate niches on Google Trends before committing (his example: compared "side hustle profit calculator" vs. "AI cost calculator" — the AI cost calculator showed a clear 5-year upward trend while the side hustle one had negligible/flat volume, so he built the AI one).
  - Trending categories mentioned as good targets right now: AI, health/fitness, GLP-1 drugs, solar/green energy, protein/creatine, side hustles.
  - Recommends picking a niche you know/care about for sustainability, though not strictly required.
- Build process demonstrated (using Hostinger Horizons, an AI/vibe-coding site builder — sponsor):
  1. Sign up for Hostinger's Starter plan (supports up to 25 websites on one plan — relevant because the strategy is to build many calculators, not just one).
  2. Prompt the AI builder directly in natural language with the exact desired functionality (his example prompt: build an "AI token cost calculator" for vibe coders to estimate token costs across popular/obscure AI models using public pricing, keep design clean/simple, and gate the result behind an email-capture form).
  3. Iterate by re-prompting or screenshotting parts of the UI and describing fixes/tweaks in plain language (e.g., simplifying "input/output token" jargon, adding real-world token-size examples, adding an interactive prompt-to-token counter, adding SEO-friendly "how to reduce token usage" tips section).
  4. Use the platform's built-in debugging assistant ("Cody" in Hostinger) to fix logic bugs by describing the desired behavior in plain language rather than needing to code it yourself.
  5. Editing plain text/copy still consumes AI credits/tokens each time you reprompt — worth doing minor copy edits efficiently/in batches.
  6. Publish with one click; connect a custom domain (his example: aitokenscalculators.com) — cited as costing "a cent" for the first year, or free using a .cloud domain included in the Starter plan.
  7. Total build time claimed: ~6 minutes from prompt to working tool; used only 4 of 70 monthly Hostinger AI credits for the whole build.
  8. Enable Google AdSense with a single one-sentence prompt to the AI builder (Hostinger has built-in AdSense integration, avoiding manual Google AdSense setup).
  9. Because Hostinger's plan supports many sites, you can copy/paste the calculator template, swap the specific niche/function, and redeploy quickly to multiple different calculator niches under one dashboard (one place to manage domains/SSL/hosting for all of them).
- Monetization specifics:
  - Google AdSense: called a good, low-friction starting point but explicitly said not to stop there. Rough math given: ~10,000 page views/month yields roughly $30–$100/month in AdSense revenue — modest.
  - Email capture: gate results behind requiring an email address (leverages sunk-cost psychology, similar to online IQ-test funnels — user has invested effort, so gives email to see the result). Rationale for valuing these emails: audience already using AI tools / vibe coding, likely to have disposable income.
  - Rough monetization comparison: if 1% of 10,000 monthly visitors give an email (100 emails) and each email is worth ~$10 (e.g., convertible to newsletter subscribers or affiliate offers), that's ~$1,000/month — over 10x what plain AdSense would generate at that traffic level.
  - Suggested use of captured emails: start a newsletter, promote affiliate links (e.g., his own Hostinger affiliate code), or other offers to that qualified list.
- Caveats/risks:
  - Presenter explicitly says the current ease of building these (via AI/vibe-coding) is a time-limited opportunity — expects this "won't be an opportunity" in 2–5 years as more people catch on / competition increases.
  - AdSense revenue at modest traffic levels is small; real upside requires higher traffic or the email/newsletter layer.
  - Sponsor content: Hostinger Horizons is a paid sponsor of the video; presenter discloses this and offers a discount code (kerneroffice/Corner Office, 10% off).
  - Success is speculative/aspirational — presenter frames outcomes as "hopefully, possibly" achieving meaningful income, not guaranteed.
