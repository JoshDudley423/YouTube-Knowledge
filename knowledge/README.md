# Compiled knowledge base

One subdirectory per topic, created as channels are added and compiled.
See the root `CLAUDE.md` for how these get built and kept current.

```
knowledge/<topic>/SUMMARY.md          the compiled, cross-channel reference -- read this first
knowledge/<topic>/videos/<id>.md      distilled notes for one source video
```

`SUMMARY.md` is organized by sub-topic/question rather than by video, states
where sources agree, and calls out explicitly where they disagree (naming
which channel/video said what). Every non-obvious claim links back to the
video note or source it came from.
